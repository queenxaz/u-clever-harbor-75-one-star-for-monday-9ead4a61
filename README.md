## The entry

> One star. Showed up at 9am, no coffee, the waiter — my alarm — screamed at me. Left hungry, tired, and already late for Tuesday.

(128 characters, limit 180, 25 words.)

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.

```sh
python3 main.py
cat /output/entry.txt
```
